Connect New Central
Connected — New Central

Device status isn't available for this API client.

Webhook key whk_… active. Add the webhook URL and API key shown when it was generated to New Central if you haven't already.

Find your cluster in New Central → Menu → API Gateway → REST API.
Select a cluster.
Enter the cluster hostname.
From New Central → Menu → API Gateway → API client credentials.
Client ID is required.
Client secret is required.
Saved only in this browser (localStorage) — never sent to or stored on the server.
New Central uses client credentials — no token download or refresh token required.
The server never writes your credentials to disk — they live only in memory for this session. Another browser starts a fresh session.

Connect Classic Central from the Connect Central tab to see its dashboard.

Connect New Central from the Connect Central tab to see your account overview.
